# 作业三交付说明：创新药公司年报/半年报问答系统

本作业以 `公司名称.txt` 为唯一公司清单，从证监会“资本市场电子化信息披露平台”抓取 13 家公司
2025 年年度报告、2025 年半年度报告、2026 年半年度报告共 **39 份 PDF 全文**，抽取文字并按行列
还原表格，切块时带上“公司 / 章节 / 页码”，建立 **Qwen3-Embedding-0.6B 向量 + BM25** 混合索引，
提供一个能提问、答案带出处的问答页面，并给出 10 道题（含 2 道跨公司全景题）的逐题召回与对错记录。

## 四、结构化与切块（要求 ②）

- 文字：PyMuPDF 按词/行还原，剔除页眉页脚、合并被换行断开的段落。
- 表格：三层策略——PyMuPDF `find_tables()`（带框线）→ 自研词坐标聚类（无框线但对齐，
  按区间重叠聚列，避免“数值列被拆成多列”）→ 质量不达标时用 pdfplumber（线条/文本策略）兜底。
  表格以 Markdown 管道表格保存，行列结构与原文一致。
- 章节：以“第X节/第X章”判定并**只允许序号向前推进**（避免财务附注里的“释义”等字样带偏），
  第八节财务报告下再挂“审计报告/合并资产负债表”等子标题。
- 切块：正文约 800 字、重叠 100 字、不跨章节；表格整表成块（过长按行分组并重复表头）；
  每块都带 `company/code/market/report_type/period/section/page_start/page_end/block_type`。
- **本作业不使用 OCR**：沪深交易所披露的定期报告是电子版 PDF，自带文字层，直接取文字层比 OCR
  更准（尤其是数字与小数点）。实测 39 份报告共 8009 页，**无文字层页面 0 页**，因此不需要 OCR；
  解析脚本对“取不到文字的页面”会记入 `report.json` 的 `empty_pages` 并在日志中列明（而非静默丢内容），
  万一将来遇到扫描件，可在此基础上接入 OCR 兜底。

## 五、索引与问答（要求 ③）

- 向量：本机已缓存的 `Qwen/Qwen3-Embedding-0.6B`（`HF_HOME=E:\HuggingFaceRepo`，离线加载），
  GPU（RTX 5060，sm_120）+ fp16；查询用 instruct 前缀、文档用 `index_text`（含公司/报告/章节/页码前缀，
  解决“表格块里没有公司名”导致的串公司问题）。
- BM25：jieba 分词（加财报/药企词表）+ 倒排索引（k1=1.5、b=0.75），并与 `rank_bm25` 分数对拍一致。
- 融合：向量与 BM25 各取 Top-100，用 RRF（k=60）融合；问题中出现公司名时对该公司块加权，
  三种模式 `hybrid / vector / bm25` 可在页面上切换。
- 问答页面：Flask 单页，**默认只输出一条“最合适的答案”**（不再是多条要点列表）：
  - **答案锚定召回排名**：只在前 3 个召回块里选，第 1 块里能找到“合格要点”就用第 1 块，
    否则顺延到第 2、3 块；合格要点 = 含实质数值 + 含问题问到的指标字段 + 不是报表套话/附注噪声
    （数值类问题），或至少命中 2 个问题实词（非数值类）。前 3 块都不合格才退回按分数选块并标低置信。
  - 答案下方给出**来源排名**（如“答案来源：召回 #1”）与置信度；多指标问题只覆盖部分问项时标为
    “部分覆盖”并提示展开候选或拆开提问；
  - 再在该块内取 1~2 条要点拼成一条答案；
    问到的字段有多个时（例如同时问营业收入与归母净利润），会在同一张表里**按字段逐行取**；
  - 答案下方只给这一条的出处（公司 / 报告 / 章节 / 页码 / 可点开的该页 PDF / 公告原文），
    其余候选答案折叠在“查看其他候选答案”里，`出处（召回的块）` 区域列出全部召回明细与三种分数；
  - **答案与出处都显示块的完整内容，不做截断**（早期版本把出处截到 420 字、答案截到 260 字，现已取消）；
    评测记录 `评测/检索记录.jsonl` 里的 `snippet` 也是完整块内容，Excel 明细另用 `snippet_short` 短片段；
  - 页面新增“答案条数”下拉（默认 1，可选 3 / 5）；问题里点名多家公司（对比题）时**自动切换全景模式**，
    每家给一条最合适的证据；
  - 若设置 `DEEPSEEK_API_KEY` 可切换生成式作答（把选出的证据改写成一句话，默认关闭、全离线）。
  可一键把本次检索写入 `评测/检索记录.jsonl`。

## 六、10 道题评测（要求 ⑤）

题目、逐题召回块、是否答对与错误原因见 `评测/十道题评测记录.md`（同内容结构化到 `.xlsx`）。
其中 **Q9、Q10 为跨公司题**（Q10 是覆盖 13 家公司的全景对比题）。评测时同时跑了四种检索方式：
`hybrid`（向量+BM25）、`vector`（仅向量）、`bm25`、`panorama`（全景：逐公司检索后合并）。

判定口径：以“抽取式答案窗口（Top5）”能否给出参考答案里的关键数值为准，召回到但排在窗口外记为
“部分答对/答错”并写明名次。结论摘要：

| --- | --- | --- | --- |

## 七、已知问题与实测结论

1. `undetected_chromedriver`（uc.Chrome）在本机实测 3 次（无头 2 次、有头 1 次）**均下载失败**，
   同一时刻普通 Selenium + 本机 Chrome 147 + 配套 chromedriver 147 成功；因此默认走 Selenium，
   `--driver uc` 仍保留为开关。
2. 证监会列表页在浏览器里偶发返回 405（requests 稳定 200），脚本按“退避重试 → 浏览器读 DOM”降级。
3. 浏览器下载必须等文件写完再搬运：早期版本在文件未落盘时搬运，出现过一份 0.10MB 的残片，
   现已改为“连续两次大小不变 + 尾部 %%EOF”校验后才接受。
4. GPU 为 8GB 且功耗受限（约 30W）：`batch_size` 过大会触发 WDDM 显存超配、速度掉 3~5 倍，
   实测 `--batch-size 24` + 最大长度 768 最稳（2.4 万块约 9 分钟）。
5. 跨公司口径差异：华东医药披露的 16.60% 是“医药工业直接研发支出 / 医药工业营收”，
   与其他公司“研发投入 / 合并营业收入”口径不同，做全景对比时需注明。
6. **启动脚本编码坑（已修复）**：早期 `启动问答页面.ps1` 是“UTF-8 无 BOM”且脚本里写了中文文件名，
   Windows PowerShell 5.1 会按 GBK 解析，把 `问答页面.py` 读成乱码并报
   `The string is missing the terminator`，页面因此起不来。现已把启动器全部改成 **纯 ASCII 内容**：
   通过“哪个 .py 里含 Flask 的 `/api/ask` 路由”来定位页面脚本，并新增 `.cmd` 双击启动器。
7. 启动体验改进：HTTP 服务先起来、模型在后台线程加载，页面顶部会显示“正在加载向量模型（已等待 N 秒）”，
   约 10~16 秒后就绪；端口被占用时会自动从 8000 往后找可用端口，并在控制台打印最终地址。
8. **向量后端容错（针对 `ModuleNotFoundError: Could not import module 'PreTrainedModel'`）**：
   该报错来自 transformers 的惰性导入，真实原因（torch 不可用、依赖链断裂、用户级 site-packages
   未被解释器加载等）会被包一层。现在 `向量模型.py` 会逐级尝试：

   1. SentenceTransformer（GPU）→ 2. SentenceTransformer（CPU）→
   3. 原生 transformers `AutoModel` + 末位池化（GPU/CPU）→ 4. 纯 BM25 检索。

   只要任一级可用页面就正常工作；即使全部失败，页面仍会**用 BM25 检索并给出带出处的答案**
   （状态栏显示“纯 BM25”），同时后台每 45 秒重试一次向量后端，恢复后自动升级为混合检索。
   每次失败都会把**完整堆栈**写进 `评测/问答页面日志.txt`。

   排障命令（各后端逐次尝试并打印真实原因）：

   ```powershell
   E:\Anaconda\python.exe .\问答页面.py --diagnose
   ```

   也可在浏览器访问 `http://127.0.0.1:8000/api/diagnose` 查看解释器、依赖版本、导入错误与后端加载日志；
   可用环境变量强制后端验证：`QA_FORCE_BACKEND=st|transformers|none`、`QA_DEVICE=cuda|cpu`。
9. **“半初始化模块”自愈（该报错的真正常见原因）**：在长期运行的 IPython / Spyder 内核里，
   某次导入失败会把一个半成品 `transformers` 留在 `sys.modules`，之后所有导入都报
   `Could not import module 'PreTrainedModel'`，即使环境本身完好。现在 `build_embedder()`
   在第一轮尝试全部失败后会**清掉 `transformers` / `sentence_transformers` 的残留模块再重试一轮**，
   实测可自动恢复为正常的向量检索。
   注意：**不建议把页面跑在 Spyder 内核里**——那样服务会挂在你的内核进程上、端口也不容易释放。
   推荐直接双击 `启动问答页面.cmd`（独立进程）。若之前已在 Spyder 里启动过，请先
   “重启内核”（Ctrl+.）释放端口，再重新启动。
10. 启动/停止细节：先绑定端口、成功后再打开浏览器（避免把浏览器开到错误端口）；端口被占用会自动
    8000→8010 依次尝试并打印最终地址；页面上新增“**关闭服务**”按钮（后端 `/api/shutdown`），
    用于关掉忘记关闭的旧实例、释放端口。
11. 单条答案的已知边界（10 题实测，详见 `评测/十道题评测记录.md` 的“单条答案”一栏）：
    - 有效：恒瑞研发投入（金额+占比）、复星/甘李的净利与同比、荣昌核心产品、跨公司研发费用率等
      都会给出“一条”正确、带页码的答案；
